# 🤖 Agent Instructions (for AI Assistants)

## 🏗️ Architecture Overview
1. **Purpose:** A proxy to query the **Google Analytics Data API (GA4)** securely without exposing `service-account.json` to client apps.
2. **Language & Framework:** Rust + `axum` + `tokio`.
3. **HTTP Client:** `reqwest`.
4. **Google Auth:** `yup-oauth2`.

## 📜 Strict Coding Guidelines
1. **Dynamic Property ID:** Do not hardcode GA4 property IDs. The payload requires `property_id` to make the service generic.
2. **Authorization:** 
   - The `/api/v1/analytics/report` endpoint expects `Authorization: Bearer <API_KEY>`.
3. **GA4 API Rules:**
   - URL: `https://analyticsdata.googleapis.com/v1beta/properties/{property_id}:runReport`
   - Read permissions scopes: `https://www.googleapis.com/auth/analytics.readonly`
4. **Rust Best Practices:**
   - Use `Arc` for shared state.
   - Map internal errors to `(StatusCode, Json<Value>)`.

End of instructions.
